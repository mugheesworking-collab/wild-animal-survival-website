# Open this folder in AntiGravity

Open **Wild-Animal-Survival-AntiGravity** as the project/workspace folder, not just `dist` and not the ZIP archive.

1. Open this entire folder in AntiGravity.
2. Open `MASTER-PROMPT.md`, copy its contents, and paste them into a new AntiGravity agent chat.
3. Run `npm run dev` in the project terminal. Node.js is required; no dependency installation is needed.
4. Preview http://127.0.0.1:4173.

All website code and assets are in `dist/`. That is also the folder to deploy to a static host. No build step is needed.

`docs/` contains the original brief, transcribed palette, prior implementation notes, handoff history and saved previews. The original color-guide PNG was in a temporary folder and is no longer present, so its exact colors and usage rules have been preserved as Markdown.

This is an independent handoff copy. The previous source, ZIP and private hosted preview have not been removed. No Codex hosting configuration, Git history or credentials are included.
