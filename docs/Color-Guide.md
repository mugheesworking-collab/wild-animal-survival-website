# Color guide — Call of Duty Mobile Tiered Black & Golden Yellow Palette

Updated October 2026 per owner direction: Shifting from green/charcoal to the signature multi-tier black palette of [Call of Duty: Mobile](https://www.callofduty.com/mobile).

## Active Palette

| Role | Tone Name | Hex Code | Visual Application |
| :--- | :--- | :--- | :--- |
| **Accent / Action** | **Golden Yellow** | `#F2B400` | Primary CTAs, active tab indicators, focus rings, claw mark, glowing dots |
| **Deep Base** | **Pitch Black** | `#000000` | Page backdrop, hero background, footer, download banner, modal overlay |
| **Layer 1** | **Void Black** | `#050507` | Deepest section shadows, header glass backdrop |
| **Layer 2** | **Dark Tier 1** | `#0A0A0D` | Secondary sections, ticker backdrop, collaborations |
| **Layer 3** | **Surface Black** | `#101015` | Gameplay mode panel base, landscape selector tabs |
| **Layer 4** | **Card Black** | `#15151C` | Cards, roster items, gallery cards, intel articles |
| **Layer 5** | **Elevated Black** | `#1B1B24` | Active card surfaces, hover elevations |
| **Hairline Borders**| **Tactical Line** | `#202028` | Fine military dividers, grid lines, card borders |
| **Strong Borders**  | **Tactical Line Strong** | `#30303C` | Hover borders, button borders |
| **Headings**        | **Pure White** | `#FFFFFF` | Condensed uppercase titles |
| **Body Text**       | **Tactical Silver** | `#D6D6DC` | High-contrast readable body text |
| **Muted Text**      | **Intel Gray** | `#8E8E98` | Eyebrow prefixes, captions, legal notes |

## Typography Reference

- **Display Headings**: `Teko`, `Barlow Condensed`, sans-serif (matching Call of Duty's *Hitmarker Condensed* font).
- **Tactical Subtitles & Buttons**: `Rajdhani`, `Barlow Condensed`, sans-serif (matching Call of Duty's *Hitmarker Text* & *Electrolize*).
- **Body & Paragraphs**: `Rajdhani`, `Barlow`, Arial, sans-serif.
